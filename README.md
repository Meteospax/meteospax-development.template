This file is created as a manual file for using and adapting this vault before using it.
There are several types of preparation operations before use.

1. Preparing the application for vault:
   1. Clone the repository;
   2. Open OBSIDIAN and open the vault management tab;
   3. In this tab, find the directory where the cloned repository is stored and open the folder as a vault.
2. Preparing the repository:
   1. Configure the repository using the PATTERNU template;
   2. Configure the repository using a specific template;
3. Preparing media data:
   1. Open the plugins tab and enable the plugin "Iconizer" for working with icons;
   2. Enable it, configure the icon archives according to the specifications (see the icon metadata);
   3. Install them using the plugin, then unzip them and use them as SVG stickers;
